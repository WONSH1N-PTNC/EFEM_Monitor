# ESAM 설치 · 커미셔닝 절차

> 대상: 신규 설치 또는 드라이버 교체 시
> 작성일: 2026-08-10
> 근거: `COMM_MAP.md` §0, `CH2.6.JKBLD300V2 User Manual_v1.1.pdf`, `ESAM_IO List_260806.xlsx`

이 문서는 **ESAM 프로그램이 수행할 수 없는 작업**만 다룹니다. 프로그램이 정상 통신을 시작하려면 그 전에 아래 설정이 끝나 있어야 합니다.

---

## 1. 송풍팬 드라이버 (JKBLD300V2) — 필수

블로워 5대(U6~U10) 각각에 대해 수행합니다.

### 1.1 보레이트를 38400 으로 변경 — **필수, 생략 불가**

> **확정 (2026-08-10)**: 블로워 드라이버는 **출하 시 115200 bps** 이며, **반드시 38400 bps 로 변경**해야 합니다.
> 이 절차를 건너뛰면 ESAM 은 해당 블로워와 **단 한 바이트도 주고받지 못합니다.**

**ESAM 프로그램은 이 작업을 할 수 없습니다.** 프로그램은 CH2 를 38400 으로 여는데 출하 상태 드라이버는 **115200** 이라, 애초에 통신이 성립하지 않습니다. 프로그램을 아무리 재시작해도 해결되지 않으며, 증상은 "블로워 5대 전부 타임아웃" 으로 나타납니다.

| 순서 | 작업 |
|---|---|
| 1 | 별도 Modbus 도구로 **115200 / 8-N-1** 접속 |
| 2 | `0x4044` 에 **2** 쓰기 (0:115200 / 1:57600 / **2:38400** / 3:19200 / 4:9600) |
| 3 | 드라이버 **전원 재투입** — 재기동해야 반영됩니다 |
| 4 | 38400 으로 재접속해 `0x4041`(현재 속도)이 읽히는지 확인 |

> 5대 각각에 대해 수행해야 합니다. 한 대라도 빠뜨리면 그 체인만 통신이 되지 않습니다.
>
> 드라이버를 교체하거나 추가할 때도 매번 필요합니다. 신품은 항상 115200 입니다.

### 1.2 슬레이브 주소 배정

`0x4000` 에 아래 값을 씁니다. 밸브가 CH2 에서 1~5 를 쓰므로 **블로워는 6 부터 시작**합니다. 같은 버스에 중복 주소가 있으면 두 장치가 동시에 응답해 프레임이 깨집니다.

| 블로워 | 위치 | 슬레이브 ID |
|---|---|---|
| U6 | EC | 6 |
| U7 | EL | 7 |
| U8 | ER | 8 |
| U9 | SL | 9 |
| U10 | SR | 10 |

### 1.3 극쌍수 설정 — 폐루프 제어의 전제

`0x4001`(Pair of poles, 1~10)에 **실제 모터의 극쌍수**를 씁니다.

드라이버는 홀 신호로 속도를 산출합니다.

```
N(rpm) = (F/P) × 60/3        F: 홀 펄스 주파수, P: 모터 극수
```

**이 값이 틀리면 `0x4041`(현재 속도)이 배수로 틀립니다.** 표시만 틀리는 것으로 끝나지 않습니다. ESAM 은 폐루프(`0x4006`)로 제어하므로 **드라이버가 잘못된 실측값을 기준으로 회전수를 조절**하게 되고, 실제 회전수가 지령과 달라집니다.

확인 방법: 임의 회전수를 지령한 뒤 `0x4041` 값과 타코미터 실측을 대조합니다. 배수 관계로 어긋나면 극쌍수가 틀린 것입니다.

### 1.4 동작 확인

아래 순서로 1대씩 확인합니다. **순서를 지켜야 합니다.**

| 순서 | 주소 | 값 | 확인 |
|---|---|---|---|
| 1 | `0x4037` | 1 | 명령 소스를 통신으로. 되읽어 1 인지 확인 |
| 2 | `0x4005` | 1 | 폐루프 모드 |
| 3 | `0x4006` | 1000 | 설정값. 되읽어 1000 인지 확인 |
| 4 | `0x4034` | 1 | 운전 개시 |
| 5 | `0x4041` | — | 1000 rpm 부근에 도달하는지 확인 |
| 6 | `0x4034` | 0 | 정지 |

`0x4037` 을 먼저 쓰지 않으면 드라이버가 IO 단자·가변저항 입력을 보므로 **이후 지령이 전부 무시됩니다.** 증상이 "통신은 되는데 팬이 안 도는" 형태로 나타나 원인을 찾기 어렵습니다.

정지는 반드시 `0x4034 = 0` 입니다. 폐루프 설정값의 최소가 **200 rpm** 이라 속도 0 지령으로는 멈출 수 없습니다.

> `0x4037` 은 기본값이 0 이라 전원 재투입 시 초기화될 수 있습니다. ESAM 은 이 값을 주기적으로 되읽어 0 으로 돌아간 것을 감지하면 재설정합니다. 다만 커미셔닝 단계에서 한 번은 손으로 확인해 두십시오.

## 2. 스로틀밸브 드라이버 — 필수

밸브 5대(U1~U5)에 슬레이브 ID **1~5** 를 배정합니다.

원점 복귀 동작을 1대씩 확인합니다.

| 순서 | 주소 | 값 | 확인 |
|---|---|---|---|
| 1 | `0x6002` | `0x0020` | Homing 실행 |
| 2 | `0x0147` | — | 완료 시 1 이 되는지 |
| 3 | `0x602B` | — | 원점에서 0 pulse 인지 |
| 4 | `0x6202` | 2500 | 목표 위치 설정 |
| 5 | `0x6002` | `0x0010` | PR0 이동 실행 |
| 6 | `0x602B` | — | 2500 pulse 도달 및 실제 개도 45° 확인 |

**5000 pulse = 90° 가 맞는지 반드시 실측하십시오.** 이 환산이 틀리면 제어 전체가 어긋납니다.

## 3. 차압센서 · PLC · 압력센서

| 장치 | 슬레이브 ID | 확인 |
|---|---|---|
| 차압센서 DP-01~13 | 1~13 | `0x4001` 읽기. 대기 상태에서 0 Pa 부근인지 |
| 온습도 THD-01 | 15 | `0x0000`~`0x0001` |
| 풍속 WS-01~03 | 20, 21, 22 | `0x0002`(에러), `0x0005`(풍속) |
| PLC | 25 | `0x000A` 비트마스크. **bit0 = EMO** |
| 압력센서 PSM | 26 | `0x03E9` 부터 FC**04** 로 21워드 |

### 3.1 PLC 디지털 입력 극성 확인 — 안전 항목

`0x000A` 를 읽으면서 각 접점을 실제로 동작시켜 비트가 맞는지 확인합니다.

| bit | 신호 | 확인 방법 |
|---|---|---|
| 0 | **EMO 비상정지** | EMO 버튼을 눌러 bit0 이 1 이 되는지 |
| 1~5 | EC/EL/ER/SL/SR BLDC 냉각팬 정지 | 해당 팬 정지 시 비트 확인 |
| 6~7 | 컨트롤박스 팬 T/B 정지 | |

**EMO 비트를 반드시 실측으로 확인하십시오.** 초안 설계는 EMO 를 D10.6 으로 가정했으나 실제는 **bit 0** 이었고, 그대로였다면 비상정지를 냉각팬 알람으로 읽었을 것입니다.

### 3.2 압력센서 소수점 위치

PSM 은 채널별로 스케일 소수점 위치가 `Dot` 레지스터(PV 주소 + 1)에 있습니다. 채널마다 다를 수 있으므로 커미셔닝 시 5채널 모두 읽어 기록하십시오.

| 채널 | PV | Dot |
|---|---|---|
| 1 | `0x03E9` | `0x03EA` |
| 2 | `0x03EE` | `0x03EF` |
| 3 | `0x03F3` | `0x03F4` |
| 4 | `0x03F8` | `0x03F9` |
| 5 | `0x03FD` | `0x03FE` |

특수값: `30000` = 상한 초과(HHHH), `-30000` = 하한 미만 또는 단선(LLLL)

## 4. ESAM 프로그램 설정

### 4.1 COM 포트 배정

`config/device-map.json` 의 `portName` 을 실제 포트로 수정합니다.

| 채널 | 기본값 | 통신 |
|---|---|---|
| CH1 | `COM3` | 19200 8-N-1 |
| CH2 | `COM4` | 38400 8-N-1 |

### 4.2 사용하지 않는 통로 비활성

기류 순환 통로가 5조 미만이면 `config/chains.json` 에서 해당 체인의 `enabled` 를 false 로 둡니다. 활성 상태로 두면 응답 없는 장치를 계속 폴링해 사이클 시간만 늘어납니다.

### 4.3 시작 시 구성 경고 확인

프로그램 기동 시 표시되는 구성 경고를 반드시 확인하십시오. 다음 항목이 나오면 해당 기능이 **동작하지 않는 상태**입니다.

| 경고 | 의미 |
|---|---|
| 안전 입력 PLC 가 구성에 없습니다 | EMO 인터록이 동작하지 않습니다 |
| 인터록 IL-03 / IL-05 비활성 | 차단기·도어 접점이 배선되지 않았습니다 |
| 주소 미확정으로 폴링에서 제외 | 해당 측정값이 화면에 나오지 않습니다 |

## 5. 미해결 확인 항목

커미셔닝 시 실측해 기록하고, 결과를 `COMM_MAP.md` 에 반영해야 하는 항목입니다.

| 항목 | 확인 내용 | 영향 |
|---|---|---|
| 슬레이브 응답 지연 | 각 장치 1대의 요청→응답 실측 [ms] | 폴링 사이클 예산이 확정됩니다. 현재 5 ms 가정이며 전체의 30% 이상을 차지합니다 |
| 밸브 pulse↔각도 | 5000 pulse 가 90° 인지 | 개도율 표시와 제어 전체 |
| 팬 극쌍수 | `0x4041` 과 타코미터 대조 | 폐루프 제어 정확도 |
| 센서 3 허용 최소 음압 | 배기 계통 설계값 | 인터록 IL-01 임계값(현재 0 Pa 잠정) |
| 차압센서 38400 지원 여부 | 데이터시트 또는 실측 | 폴링 주기 개선 여지 |

## 6. JKBLD300V2 매뉴얼 주의

매뉴얼 안에서 예제가 표와 어긋나는 곳이 있습니다. **표를 기준으로 삼되 실측으로 확인하십시오.**

- §7.4 속도 읽기 응답이 `0x0E38`(3640)인데 캡션은 "current speed is 1000rpm"
- §7.7 예제가 `0x4007` 에 `0x32`(50)를 쓰고 "50%" 라 설명하나, 표는 100~1000 이 10~100% 이므로 50% 는 500 이어야 함

ESAM 은 개루프(`0x4007`)를 사용하지 않으므로 두 번째 항목은 실사용에 영향이 없습니다. 다만 `0x4041` 의 스케일은 첫 번째 항목과 극쌍수 설정에 함께 걸리므로 §1.3 의 타코미터 대조로 확인해야 합니다.
